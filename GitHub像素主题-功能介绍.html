核心功能

鼠标经过，网格留下颜色

以 GitHub 首页的像素网格互动为灵感，指针经过时点亮绿色、紫色、橙色与蓝色方块。颜色短暂停留后淡出，让新会话页拥有轻巧的反馈。

可开启点击扩散，调整像素大小、消退速度、色块强度、网格可见度及帧率。背景可以只在新会话显示，也可以延伸到聊天页。

Clawd，在输入框上陪你工作

Claude Code 风格的像素小螃蟹站在输入框上沿，跟随思考、输出和等待确认等状态切换姿态。单击它，会拿出电脑；双击，则会作出挠痒反应。

随包包含 19 组动画与墨色蒙版。宠物大小、显示范围和启用状态都可单独设置，长时间无操作时会进入休息姿态。

让星芒标记输出与完成

输出时，用一枚 Claude 风格的呼吸星芒替换原生鲸鱼尾巴，保留 Harness 原来的状态文字、计时与无障碍播报。回复结束后，在末尾留下一个静态星芒签名。

输出图标与回复签名可以分别设置。v1.2.2 已修复两种输出图标叠加的问题，显示效果与选项保持一致。

签名是页面上的独立装饰，不写入消息正文、模型上下文或复制文本。星芒颜色也可以独立修改。

把底色调成你的习惯

GitHub、DeepSeek、森林、暮色四套配色，加上自定义方案。支持浅色、深色，以及跟随系统或宿主外观。

  • 主界面、侧边栏、输入框与卡片分别改色。使用选色器，或直接输入六位十六进制色号。
  • 文字深浅随底色调整。方便搭配深色侧边栏与浅色聊天区等组合。
  • 布局一起调整。支持 12–20 px 正文字号、600–1280 px 对话宽度、0–24 px 卡片圆角，以及系统、无衬线、等宽字体。

六组设置，一个入口

右下角四色按钮 / 像素主题设置

也可以通过 Harness 设置中的“像素主题”进入。设置即时生效，常用功能都能独立开关。

设置分组可以调整什么
外观主题启用、亮暗模式、配色方案、强调色
底色主界面、侧边栏、输入框与卡片的浅色和深色底色
像素互动拖尾、点击扩散、角落彩色方块、大小、消退时间、强度、网格及帧率
宠物星芒Clawd 开关、范围和大小，输出星芒、回复签名、签名范围和颜色
布局字体字体、正文字号、对话宽度和卡片圆角
配置JSON 导入、导出、恢复默认

Harness 配置服务可用时，设置保存在当前 profile；否则保存在当前浏览器。导出 JSON 后，可以在另一台设备或另一个浏览器中导入。

关于左右上角的四色方块

它们是“角落彩色方块”静态装饰，会持续显示。在“像素互动”中关闭这一项即可隐藏，网格和鼠标拖尾仍可继续使用。

快速安装

  1. 下载并解压主题 ZIP

    里面包含本地安装包、安装脚本、独立预览、使用说明与完整源码。

  2. 关闭其他完整主题，运行安装脚本

    Windows 用户配置好 dsh 命令后，可双击“安装到桌面版.cmd”。它会调用已有的 Harness CLI 安装旁边的 .tgz 包。

  3. 重启 Harness，启用 GitHub Pixel

    打开新会话，在空白处移动鼠标；右下角四色按钮可以打开全部主题设置。

使用命令行安装

在 .tgz 文件所在目录运行：

PowerShell / 终端
dsh plugin --profile desktop add "./dsh-github-pixel-theme-1.2.3.tgz"

网页版将 desktop 换成对应 profile，例如 web，然后重启服务并刷新页面。安装脚本使用 PATH 中的 dsh 命令；也可在自己的 Harness CLI 终端中安装。

主题未发布到 npm，安装时请使用 ZIP 内的本地 .tgz 文件。旧版用户可按相同步骤更新，原有配置格式保持兼容。

从旧版更新

安装 v1.2.3 后重启 Harness，再到“宠物星芒 / 输出中状态”选择所需图标。原有主题配置可继续使用；已打开的介绍页请重新打开，以载入本次更新的演示。

常见问题

侧边栏输入颜色后没有变化？

请更新至 v1.2.3 并重启 Harness。新版本适配了真实侧边栏，完整色号输入后立即生效。浅色外观使用“侧边栏 · 浅色模式”，深色外观使用对应的深色模式颜色。

星芒和鲸鱼尾巴还会同时显示吗？

v1.2.2 已修复输出图标叠加。选择“Claude Code · 呼吸星芒”时只显示星芒；选择“Harness 原生”时只显示原生鲸鱼尾巴。状态文字与计时保留。若更新后仍看到旧效果，请确认已安装 v1.2.2，并重启 Harness。

主页还有像素鲸鱼吗？

v1.2.1 起已在主题启用时隐藏 Harness 自带的首页像素鲸鱼画布。输入框上沿的 Clawd 宠物单独保留，可在“宠物星芒”中关闭。

只想要网格背景，可以关闭宠物和星芒吗？

可以。“桌面宠物”“输出中状态”“回复签名”分别设置即可。输出中状态可切回 Harness 原生，宠物和签名可各自关闭。

为什么在预览页调好的设置没有出现在 Harness 中？

本地 HTML、不同浏览器与 Harness 的存储相互独立。可在“配置”中导出 JSON，再到 Harness 导入。

动效会一直运行吗？

像素背景在没有拖尾需要绘制时不会持续刷新；窗口不可见时，背景和宠物动画会暂停。系统开启减少动态效果后，背景保留静态网格，宠物采用静态姿态，呼吸星芒也会停止动画。

如何恢复原生界面？

关闭“启用主题”可临时恢复，四色设置入口仍保留。彻底停用则在 Harness 插件管理器关闭或卸载主题，再重启应用。

适用范围与验证

面向 DeepSeek Harness Desktop 与 Web 的 0.2.x 界面，声明最低版本为 0.2.1-rc.3。本机运行时为 Desktop 0.2.1-rc.5。

已通过 12 项自动测试，并完成浏览器预览中的配色、状态切换、签名范围、原生图标恢复、减少动效与卸载清理验证。真实模型会话及不同实体手机的表现未作完整实测；宿主后续更新可能需要适配。
